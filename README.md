# Lab Summaries

### Lab 01 — VM Setup & VIM
Setup of Linux VM, snapshots, and VIM proficiency.

### Lab 02 — Advanced VIM & OpenRedAlert!
Source code editing, debugging, and policy/compliance fundamentals.

### Lab 03 — Linux File Systems & Security Models
Linux permissions, directory management, Bell–LaPadula confidentiality model.

### Lab 04 — Cryptographic Hashes & Linux File Operations
MD5/SHA hashing, collision resistance, SUID security tasks.

### Lab 05 — Symmetric Crypto & SUID Integration
AES encryption/decryption, Base64, secure SUID-based message system deployment.

### Lab 06 — PKI & Apache HTTPS Deployment
Certificate Signing Requests (CSR), CA signing, RSA encryption, HTTPS setup.

### Lab 07 — Secure Design Principles & Process Management
Security architecture, Linux process monitoring (ps/top/kill/strace), scheduling with cron.

### Lab 08 — Networking, SSH, DNS, Netplan
Static IP configuration, SSH/SFTP, Apache hosting, DNS (bind9) setup.

### Lab 09 — LDAP Directory Services & SSO
LDAP server configuration, ldapscripts, NSS/PAM integration, centralized authentication.

### Lab 10 — NFS & Enterprise Single Sign-On
NFS server/client setup, remote home directories, LDAP-integrated SSO, enterprise-style file access.
