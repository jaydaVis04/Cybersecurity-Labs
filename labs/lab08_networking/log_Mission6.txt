Q1. Senator Coleone

Our job is to set up two server names: president.corleone.org and senator.corleone.org, and map them to 169.254.251.1 and 169.254.251.2, respectively. In another word, the main image will have the name senator and the Vegas image wil have the name president, and both of them belong to DNS zone corleone.org
  The DNS server (bind9) will be set up at 169.254.251.1 (the Vegas image). We suggest that you follow the steps below (as illustrated in the tutorial):
    (1) No need to modify the named.conf.options file. This step is actually extra
    (2) Modify named.conf.local to add a zone named 'corleone.org', specify that the zone details is contained in a file 'db.corleone' 
    (3) Create the db.corleone file as shown in the tutorial, and add at least two A records (the entries for senator and president) into it.
    (4) validate, and run as suggested. You can verify on the main image using the following command:
	 nslookup president.corleone.org 169.254.251.1
Here the 2nd parameter specifies the location of the DNS server

Make sure that senator.corleone.org is mapped to 169.254.251.2!
